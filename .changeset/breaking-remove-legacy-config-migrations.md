breaking(config): Volt no longer migrates or reads configuration, credential, package, daemon, and remote-host files in pre-release formats.

Migration: rename pre-namespaced ids in `keybindings.json` (for example `cursorUp` to `tui.editor.cursorUp`, `expandTools` to `app.tools.expand`) using the ids `/hotkeys` lists. In `settings.json`, replace `queueMode` with `steeringMode`, `websockets` with `transport` (`"websocket"` or `"sse"`), a `skills` object with a list of skill directories plus `enableSkillCommands`, and `retry.maxDelayMs` with `retry.provider.maxRetryDelayMs`. Move credentials from `oauth.json` or `settings.json` `apiKeys` into `auth.json` with `/login`, and rename a `commands/` directory to `prompts/`. User npm packages are no longer loaded from the global npm or pnpm root; Volt installs them into `~/.volt/agent/npm` on the next start. A `remote/iroh-host.json` from before the daemon is no longer imported, regenerating a daemon `state.json` from before access grants (`volt daemon regenerate-state` or `/remote`) now starts empty state with a new Iroh identity, and a `state.json` missing any host-state section or a workspace's generation record is reported as invalid instead of being filled in; pair phones again. SDK: `InteractiveModeOptions.migratedProviders` is removed, the daemon runtime factory takes `toolPolicy` instead of `allowTools`, the `IrohRemoteGrantedClient`, `IrohRemoteGrantedRevokedClient`, and `IrohRemoteGrantedPendingPairingTicket` types are removed because every record now carries `rpcGrant`, and every `IrohRemoteHostState` section is required. Daemon control protocol: `status_result` no longer carries `capabilities`, and `revokedClients`, `remotePolicy`, and each client's `allowedTools`, `usesDefaultTools`, and `rpcGrant` are always present.
