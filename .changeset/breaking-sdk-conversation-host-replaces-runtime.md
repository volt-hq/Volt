breaking(sdk): The SDK hosts sessions in a `ConversationHost` instead of `AgentSessionRuntime`, and an extension command run through an RPC `prompt` can now change sessions. ([#585](https://github.com/volt-hq/Volt/issues/585))

Every mode (TUI, print, JSON, stdio RPC, daemon phone streams, subagents) is a client of a `ConversationHost`. The host binds a session's extensions once, in the host's `extensionMode` (`ctx.mode`), and attaches each client's surface (UI, session actions, error listener) whenever the client joins a session, including the one a session change moves it to. A session change opens the new session, fires its `session_start`, then closes the old one with its `session_shutdown`. An extension command that calls `ctx.newSession()`, `ctx.fork()`, or `ctx.switchSession()` from a stdio RPC or phone `prompt` no longer fails with "durable client input outcome is ambiguous": its own prompt input completes as it leaves the session.

Migration: replace `createAgentSessionRuntime(factory, { cwd, agentDir, sessionManager })` with `new ConversationHost({ factory, agentDir, extensionMode })` and `host.open({ kind: "adopt", sessionManager, cwd })`, then attach a `HostClient` (`id`, `anchor`, `surface`, and `move: { kind: "in_place", prepare?, onMoved }`) with `host.attach(client, conversation)`. Replace `runtime.newSession()`, `switchSession()`, `fork()`, `importFromJsonl()`, and `executePlan()` with `openNewSession(host, client, ...)`, `openStoredSession()`, `openStoredSessionById()`, `openFork()`, `openImport()`, and `executePlan(host, client, ...)`. Move the work of `setRebindSession`, `subscribeSessionReplaced`, and `setBeforeSessionInvalidate` into the client's `onMoved` and `prepare`; put the client's extension UI, session actions, and error listener in its `surface` instead of attaching to each new session yourself. Read `runtime.session`, `services`, `diagnostics`, `reviewWorkflows`, `lost`, and `conversationProjectionFeed` from the `HostedConversation` (`projectionFeed`), and close it with `host.close(conversation)` or `host.dispose()` instead of `runtime.dispose()`. `CreateAgentSessionRuntimeFactory` is now `ConversationFactory`, `CreateAgentSessionRuntimeResult` is `ConversationFactoryResult`, and `AgentSessionRuntimeDiagnostic` is `AgentSessionDiagnostic`. `runPrintMode`, `runRpcMode`, and `createInProcessRpcClient` take `(host, conversation, options)`, `new InteractiveMode(host, conversation, options)`, and the RPC option `disposeRuntimeOnClose` is now `anchor`. `SubagentManager`'s `onRuntimeCreated` event carries the child's `host` and `conversation` instead of `runtime`.
