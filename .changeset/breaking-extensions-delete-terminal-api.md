breaking(extensions): The terminal-only extension API is removed: extensions show their UI only as data (status items, panels, notifications, dialogs, forms, and presentations), which every client renders the same way. ([#585](https://github.com/volt-hq/Volt/issues/585))

To migrate, replace each removed member: `ctx.ui.setWidget` with `ctx.ui.setPanel(name, {placement, node})`; `ctx.ui.setFooter` with `ctx.ui.setStatus(key, text)` status items; `ctx.ui.setHeader` with an `aboveEditor` panel or `ctx.ui.notify`; `ctx.ui.custom` with `ctx.ui.form`, `ctx.ui.dialog`, `ctx.ui.select`/`confirm`/`input`/`editor`, or a panel; `ctx.ui.onTerminalInput` with `volt.registerShortcut(key, {intent})` mapping a key to an intent from `volt.registerIntent` or to a command; `ctx.ui.addAutocompleteProvider` with `volt.registerCompletionProvider(name, {trigger, complete})`; `ctx.ui.theme` and `ctx.ui.getTheme` with semantic tokens in `StyledText` and `UiNode` data. `ctx.ui.setWorkingMessage`, `setWorkingVisible`, `setWorkingIndicator`, `setHiddenThinkingLabel`, `setEditorComponent`, `getEditorComponent`, `getToolsExpanded`, and `setToolsExpanded` have no replacement (use `ctx.ui.setStatus`, `setEditorText`, `pasteToEditor`, `getEditorText`, and shortcuts); the client owns tool expansion. `ctx.ui.getEditorText` is asynchronous and `ctx.ui.setTheme` takes a theme name only.

Tool definitions render only through `present()`: `renderCall`, `renderResult`, `disposeRenderState`, `renderShell`, `rendersDuration`, and the `ToolDefinition` third type parameter are removed, as are `ToolRenderContext` and `ToolRenderResultOptions`. Custom messages render only through `volt.registerMessagePresenter`: `volt.registerMessageRenderer`, `MessageRenderer`, and `MessageRenderOptions` are removed. Dismissed dialogs resolve `undefined`; `ExtensionUIDismissedError` is removed. The types `TerminalInputHandler`, `WorkingIndicatorOptions`, `AutocompleteProviderFactory`, `EditorFactory`, `ExtensionWidgetOptions`, `WidgetPlacement`, `ExtensionTerminalUI`, `ReadonlyFooterDataProvider`, `KeybindingsManager`, and `AppKeybinding` are no longer exported. `@hansjm10/volt-coding-agent` no longer exports TUI components (`CustomEditor`, `BorderedLoader`, `DynamicBorder`, `FooterComponent`, the selectors, `keyHint`, `renderDiff`, and the rest) or the ANSI theme helpers (`Theme`, `ThemeColor`, `initTheme`, `getMarkdownTheme`, `getSelectListTheme`, `getSettingsListTheme`, `highlightCode`, `getLanguageFromPath`). SDK clients attaching with `attachExtensionClient` pass `themes` (`getAllThemes`, `setTheme`) instead of `ui`.
