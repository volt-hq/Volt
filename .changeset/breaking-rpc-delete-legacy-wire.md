breaking(rpc): The legacy RPC command, response, and event schemas are removed from `@hansjm10/volt-protocol` and its contract artifact, and hosts now reject identifiers and conversation input past their byte limits. ([#585](https://github.com/volt-hq/Volt/issues/585))

The contract artifact (`contract/protocol-schema.json`) declares only protocol 1 frames, log entries, the daemon control protocol, the Iroh handshake, and `UiNode`. The `RpcCommand`, `RpcResponse`, `RpcServerEvent`, and `RpcClientMessage` definitions, the UI action, transcript, session state, and stream frame definitions, and the `x-volt-open-events` note are gone. `x-volt-limits` drops the session state, transcript, session tree, message image, and error code sections; the remote profile's bounds are under `remoteProfile`, and the queue depth is `conversationInput.queueMaxItems`. Intent descriptors carry `IntentStateValue`, `IntentPresentation`, and `IntentSlashAlias`, and `intent_completions` returns `IntentOption`s. Intents and queries reject an identifier longer than 256 UTF-8 bytes, a message longer than 512 KiB, and more than 8 images as `invalid_input`; a frame whose `intentId`, `queryId`, or `subscriptionId` is longer than 256 UTF-8 bytes ends the connection with `fatal{invalid_frame}`. An embedded `runRpcMode(..., { exitProcess: false })` now rejects with the log's error when its conversation loses its log, instead of resolving. The daemon audit log records a completion notification it skipped for a device without an enabled push target as `push_notification_skipped` (was `push_notification_fallback`).

Migration: import protocol types from `@hansjm10/volt-protocol` (`ClientFrame`, `HostFrame`, `IntentDescriptor`, `IntentInput`, `QueryResult`, `LiveValue`) instead of the `Rpc*` and `UiAction*` types `@hansjm10/volt-coding-agent` re-exported (`RpcCommand`, `RpcResponse`, `RpcSessionState`, `RpcExtensionUIRequest`, `RpcTranscriptItem`, `UiActionDescriptor`, and the rest); payload types such as `RpcGitContext`, `RpcCatalogModel`, and `RpcSessionListItem` are exported by `@hansjm10/volt-protocol`. Session event listeners receive `fast_mode_changed{enabled}` instead of `ui_action_state_changed`. Subagent handles no longer have `getState()` or `getTranscript()`: subscribe to the child's conversation, or read `handle.conversation`.
